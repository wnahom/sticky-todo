# 📌 Sticky Todo — 磁贴待办清单

**零依赖**，只需 Node.js，一条命令启动。

## 启动

```bash
node server.js
```

浏览器自动打开 http://localhost:4321

## 功能

- ✅ 待办清单管理（添加/编辑/勾选/删除）
- 📋 磁贴模式（Alt+T 切换，花笺风格圆角装饰）
- ⏰ 闹钟提醒（系统通知）
- 🔍 搜索与过滤
- 🎨 设置面板（透明度调节）

## 快捷键

| 按键 | 功能 |
|------|------|
| `Enter` | 添加待办 |
| `Ctrl+N` | 聚焦输入框 |
| `Alt+T` | 切换磁贴模式 |
| `Alt+M` | 返回主视图 |
| `Esc` | 关闭面板 |

## 数据

- 待办数据保存在 `data.json`
- 设置保存在 `config.json`
- 两个文件都在项目根目录，可手动编辑

## 架构

纯前端单页应用，无框架、无依赖。Node.js 仅用作静态服务器 + JSON 数据读写 API。
